PROMPT ID: P1 — Advisory Generation
Workflow task: Generate an advisory from supplied forecast data.
Purpose: Produce a concise, source-grounded draft advisory.
Implementation note: The deployed Python prototype does not call an external LLM. It builds the selected Baseline or Structured prompt and returns rule-based mock output.
User template:
Generate a heat-wave public-health advisory using the information below.
Forecast: {forecast_text}
Location: {location_or_not_provided}
Date/period: {date_or_period_or_not_provided}
Temperature: {temperature_or_not_provided}
Official warning level: {warning_level_or_not_provided}
Audience: {audience}
Language: {language}
Maximum words: {max_words}
Use only supplied facts. Separate forecast facts from general precautions. Identify missing information. Output: Headline; Main Advisory; Practical Precautions; Missing or Uncertain Information.
Variables: fields in braces contain user-supplied forecast/audience/output constraints.
