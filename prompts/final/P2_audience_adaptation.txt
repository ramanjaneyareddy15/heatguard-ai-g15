PROMPT ID: P2 — Audience Adaptation
Workflow task: Adapt a factually grounded advisory for a specified audience.
Purpose: Change wording and practical examples without changing forecast facts.
Implementation note: This prompt sheet documents the task design. The deployed Python prototype does not call an external LLM.
User template:
Adapt this heat-safety advisory for {audience}.
Original forecast: {forecast_text}
Existing advisory: {advisory_text}
Language: {language}
Maximum words: {max_words}
Preserve every forecast fact. Do not assume missing details or invent warning levels, dates, locations or temperatures. Include relevant audience-specific general precautions. Explicitly identify missing information.
Output: Headline; Audience-specific Advisory; Recommended Precautions; Missing or Uncertain Information.
Variables: audience, forecast_text, advisory_text, language and max_words are supplied by the user.
