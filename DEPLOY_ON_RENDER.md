# Deploy HeatGuard AI (offline prototype) on Render

This repository is configured for Render Web Services. Important: the current backend returns rule-based MOCK advisory output; it is not connected to Gemini.

## 1. Publish the repository on GitHub
1. Sign in to GitHub and create a new **public** repository named `heatguard-ai-g15`.
2. Upload the contents of this folder to the repository root (not the enclosing folder).
3. Commit the files. Do not upload API keys or passwords.

## 2. Deploy
1. Open https://render.com/ and sign in.
2. Choose **New +** → **Web Service**.
3. Connect GitHub and select `heatguard-ai-g15`.
4. Render should detect `render.yaml`; if asked, use runtime Python, build command blank, start command `python backend.py`.
5. Deploy and wait for the service to become Live.
6. Open the `onrender.com` URL Render provides and test the homepage and workflows.

## 3. Important for evaluation
- The public URL is generated by Render after deployment; it cannot be pre-created from this workspace.
- Test the link in an incognito/private browser before sharing it.
- Label the app honestly as an offline/mock prototype unless Gemini API integration is implemented and tested.
- A public GitHub repository and a live Render service require you to authorize your own accounts. Never share your password or API key in chat.
